# Canonical glossary

| Term | Definition |
| --- | --- |
| Organization | Entity that operates or receives platform-supported programs. |
| Program | A bounded initiative operated by an Organization. |
| Need | A documented gap or desired outcome. |
| Signal | An immutable observation relevant to a Need. |
| Opportunity | An actionable grouping of a Need and supporting Signals. |
| Recommendation | A proposed, non-authorizing allocation response to an Opportunity. |
| Approval | An explicit governance decision authorizing a Recommendation. |
| Allocation | An authorized commitment of funds, identified by `allocationId`. |
| Execution | The fulfillment activity for an Allocation. |
| Evidence | An attributable artifact or claim supporting what occurred. |
| Receipt | A transaction record issued during Execution. |
| Verification | An assessment of Evidence and Receipt against a claim. |
| Impact | A verified outcome claim attributable to an Allocation. |
| Notification | A delivery request or record for a lifecycle update. |

Capitalized glossary terms are normative. Do not replace them with synonyms such as “grant” for Allocation or “proof” for Evidence without defining a distinct concept.
