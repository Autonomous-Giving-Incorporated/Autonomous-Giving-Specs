# Repository conformance validation

The repository validates links, schema syntax, artifact inventory, and duplicate glossary terms in CI. Reviewers additionally apply the [validation checklist](../docs/validation.md) and the conformance rules in [SPEC-013](../specs/SPEC-013-repository-conformance.md).

Validation MUST reject broken references, orphan normative artifacts, missing owners, invalid schema references, duplicate canonical terms, and lifecycle alternatives.
