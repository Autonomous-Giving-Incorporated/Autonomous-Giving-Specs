## Purpose

Make the repository authoritative, reviewable, and navigable over time.

## Requirements

All normative documents use stable IDs, front-matter tables, relative links, canonical glossary terms, explicit owner and status, and reviewable rationale. Diagrams have source text in this repository. New terms require glossary updates. See the [documentation standards](../docs/standards.md).
