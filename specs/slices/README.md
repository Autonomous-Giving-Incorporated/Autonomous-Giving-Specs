# Spec-kit slices

Informative specify → plan → tasks folders for later runtime work. They are **not** new SPEC identifiers and they are **not** accepted platform authority.

Normative rules stay in `specs/SPEC-*.md`. A slice MUST NOT contradict its parent SPEC. A slice MUST NOT mark READY, invent a live host, or add application code.
