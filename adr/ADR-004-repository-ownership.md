# ADR-004: Repository Ownership

| Status | Accepted |
| --- | --- |
| Date | 2026-08-03 |
| Related specs | SPEC-001, SPEC-009 |

## Context

Architecture loses authority without clear stewardship.

## Decision

Platform Architecture owns repository canon; domain owners own their artifacts; consuming implementations review breaking changes.

## Consequences

Every contract and SPEC declares an accountable owner.
