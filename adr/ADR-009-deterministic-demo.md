# ADR-009: Deterministic Demo

| Status | Proposed |
| --- | --- |
| Date | 2026-08-03 |
| Related specs | SPEC-007, SPEC-008 |

## Context

Live demos obscure whether the system's proof chain works.

## Decision

Adopt Community AI Lab with fixed artifacts as the canonical demonstration.

## Consequences

Implementations can demonstrate the same lifecycle without external dependencies.
