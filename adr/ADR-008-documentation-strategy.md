# ADR-008: Documentation Strategy

| Status | Accepted |
| --- | --- |
| Date | 2026-08-03 |
| Related specs | SPEC-009, SPEC-010 |

## Context

Reference documents need durable discoverability and review rules.

## Decision

Use numbered Markdown artifacts, relative links, Mermaid source diagrams, a glossary, and validation checks.

## Consequences

Documentation changes are treated as versioned architectural changes.
